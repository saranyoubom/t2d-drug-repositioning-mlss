# Protocol v2: calibrated checks for the pooled co-expression pipeline (pre-specified 4 Nov 2026)

Written before any analysis below was run, except the disclosed planning reconnaissance on the INS-1 data (`recon_run_structure.py`, section 1). Fingerprint in `PROTOCOL_v2_SHA256.txt`. Every deviation goes in section 8 with a timestamp, before the affected result is seen where that is possible. All results are reported whichever way they point. Nothing is tuned after seeing a result. The reported analysis of the manuscript stays the primary analysis; everything here is a calibration or sensitivity layer around it.

## 1. Why this protocol exists
1. Route 3 part 1 (`../benchmark_route3/`): the test of the consensus COUNT against the permutation null flagged injected within-group coupling in only 27% of 37 datasets (pre-set requirement 80%). The count cannot detect coupling, so "count within the null" is not evidence of absence.
2. Reconnaissance on INS-1 (post hoc, 4 Nov): treatment-adjusted q < 0.05 counts [raw, Ins1, Kcnj11, Hes1] were 0, 51, 11, 15, against 0.1, 29.0, 11.6, 6.4 with independent within-group residuals (P 1.0, 0.087, 0.465, 0.074). Ratio schemes share a denominator, so BH on them is not calibrated.
3. Same reconnaissance: within-group r on the raw scale, same-run gene pairs mean +0.41 (n = 29), between-run pairs mean -0.07 (n = 107), MWU P = 0.0007 for |r|; consensus pairs same-run 7/20 vs between-run 14/71 (Fisher P = 0.23; provisional gene-to-run map). Replicate order across runs has no verified physical meaning (the manuscript states the well-to-replicate pairing was lost), so between-run pairs are a natural negative control and same-run pairs share one Gapdh value per replicate.

Sections 2 (INS-1) are therefore post hoc and must be labelled post hoc wherever they are reported. Sections 3-5 use data not yet analysed.

## 2. INS-1 analyses (post hoc, labelled as such)
Input: the 17-gene matrix used by the manuscript. On the authors' calculation sheets only the row order of the sheets is used; lost well-to-replicate mappings are NOT reconstructed.
* **2.1 Gene-to-run map.** For each of the 17 genes find the run(s) whose calculation-sheet values equal the matrix values (exact match; Table S1c lists the runs). Output `gene_run_map.csv` with the evidence. A gene that cannot be matched is marked unresolved and excluded from the run tests, and the map is the only source for later steps (the provisional map in the recon script is replaced).
* **2.2 Run-structure test.** D = mean within-group r over same-run pairs minus mean over between-run pairs (Pearson on log-scale residuals after removing group means; raw scheme). Null: permute run labels across genes preserving run sizes (20,000 permutations, seed 2026). Two-sided P. Secondary: the same for |r|. Reported per run.
* **2.3 Enrichment of consensus pairs and hubs by run.** Among the 91 pairs eligible for consensus: same-run vs between-run counts, Fisher test and the gene-label permutation of 2.2. Degree of each hub vs the size of its run.
* **2.4 Shared-reference contribution.** Where per-replicate target Cq and reference values exist on the sheets: within-group r of same-run pairs on target Cq (no reference) vs on dCq. Then two sensitivity versions of the pooled analysis: (a) each replicate's reference replaced by the run-and-group mean of Gapdh (removes per-replicate reference noise); (b) each replicate's reference replaced by the run-wide Gapdh mean (removes reference shifts between groups, i.e. no normalization within run). Report consensus count, pairs kept/lost, and hubs for each. Where sheets do not allow it, say so.
* **2.5 Calibrated adjusted counts.** For each scheme: observed q < 0.05 count against its distribution under independent within-group residuals (2,000 permutations, seed 2026), P(null >= observed). Raw-scheme q values listed per pair; the ratio schemes are reported as artefact-prone.
* **2.6 Within-group coupling tests on INS-1.** T_r2 (section 3.1) overall, for same-run pairs and for between-run pairs. **Run-block permutation null for the consensus count**: within each group permute replicate labels jointly for all genes of a run (keeps same-run coupling, destroys any between-run pairing); observed count against this null.
* **2.7 Geometric expectation.** With 3 groups the centred group-mean vector of a gene lies in a 2-dimensional plane. If pooled r is carried by group means and orientations are uniform, P(|r| >= r_crit) = (2/pi) x arccos(r_crit); for r_crit = 0.576 (p = 0.05, df = 10) this is 0.61. Compare with the observed share of pooled-significant raw pairs among genes with a group effect (ANOVA FDR < 0.05), INS-1 and benchmark. Reported as an anchor, not a test.
* **2.8 Scale sensitivity.** Consensus count, null, covariance share on (a) log scale Pearson, (b) Spearman.

## 3. Benchmark part 2 (same pipeline, new tests, held-out data)
* **3.1 Tests.** All on log-scale residuals after removing group means, raw scheme, null = independent within-group permutation per gene (2,000 permutations). **T_r2 (primary)** = mean squared off-diagonal correlation. T_p = number of pairs with p < 0.05 at the residual df. T_eig = largest eigenvalue of the residual correlation matrix. The consensus-count test of part 1 is kept for comparison.
* **3.2 Calibration on decoupled data.** For each development series and gene set A: permute residuals within group (removes coupling), then inject one latent factor, centred within group, into m genes with loading lambda = sqrt(r/(1 - r)) x the gene's pooled within-group SD: r in {0.3, 0.5, 0.7, 0.9}, m in {3, 6, 10}. At least 20 replicates per series and condition, 500 permutations each. No injection (at least 100 replicates per series) gives type I error. The count test is run on m = 6 at a reduced replicate number (at least 5), which is declared in the output. **Requirement: T_r2 type I error <= 0.06 and power >= 80% at r = 0.7, m = 6.** If it fails, it is reported as failing and the best-performing pre-listed statistic is named as secondary, not substituted silently.
* **3.3 Real-data application.** Development and validation sets, gene sets A and B: prevalence of within-group coupling (P < 0.05) with Wilson 95% CI.
* **3.4 Ratio-scheme diagnostics.** Per series and scheme: observed adjusted q < 0.05 count vs null (500 permutations), share with P < 0.05, median observed/null ratio. Part 1 endpoint E2 is recomputed on the raw scheme alone.
* **3.5 Held-out validation sets, frozen before any expression value is read.**
  * Arrays: positions 151-450 of the same shuffled lists (GPL570, GPL1261; `../benchmark_route3/select_datasets.py` rules, `N_SCREEN` window changed only), series sharing a sample with the development set excluded; dry run on DE counts; target 20 analysable per platform.
  * RNA-seq: GEO series with NCBI-generated raw counts (`geo/download/?type=rnaseq_counts`): query `("Homo sapiens"[Organism] OR "Mus musculus"[Organism]) AND "Expression profiling by high throughput sequencing"[DataSet Type] AND gse[ETYP] AND 12:36[n_samples] AND (treated OR treatment OR knockdown OR inhibitor OR stimulated OR overexpression OR siRNA OR shRNA OR agonist OR cytokine)`, shuffled with `random.Random(2026)`, first 300 per organism screened on metadata by the same rules, then counts must exist. Linear scale = CPM on all genes; genes need count >= 1 in all 12 samples; expressed and DE as in part 1 on log2(CPM + 1). Target 20 analysable per organism. If NCBI counts cannot be downloaded the arm is reported as not done.
* **3.6 Endpoints on validation sets.** The part 1 endpoints E1, E2 (raw scheme and all schemes), E3 and the raw pooled-significant share (2.7), plus 3.3 and 3.4. Reported per set and pooled. The part 1 positive control is not repeated; 3.2 replaces it.
* **3.7 Design guidance.** Simulation with G = 17, one module of m = 6 genes at within-group r in {0.3, 0.5, 0.7, 0.9}, n per group in {4, 6, 8, 12, 20, 30}, 3 groups (seed 2026): power of T_r2 and of per-pair detection (BH q < 0.05, residual df), plus the analytic |r| needed for the single best pair. Replicates in this table mean independent experiments; wells from one preparation do not count.

## 4. Public islet cross-check, version 2
* **4.1** The existing GSE81608 and GSE84133 results stay as reported and are reproduced first (gate).
* **4.2 Depth adjustment.** Within beta-cells: centre each gene on its donor mean, regress on log10 library size (UMI data) or log10 number of detected genes (RPKM/TPM data) with a quadratic term, rank the residuals, correlate (partial Spearman). The expression-matched null is rebuilt on the adjusted data. Reported beside the unadjusted result.
* **4.3 Further human datasets.** Attempted in this order, only with author-provided beta-cell labels and plain public download: GSE86469 (Lawlor 2017), GSE81547 (Enge 2017), E-MTAB-5061 (Segerstolpe 2016), GSE85241 (Muraro 2016). All attempts and failures are listed. Same evaluable rule (10% detection).
* **4.4 Primary endpoint, meta-analysis.** Per human dataset with at least 3 evaluable consensus pairs: excess E = mean Fisher z of the evaluable consensus pairs minus the mean over 2,000 matched random pair sets (depth-adjusted), SE from that null distribution. Random-effects pooling with Hartung-Knapp 95% CI. **Decision rule fixed now, margin +/-0.10 (rho = 0.10 explains 1% of variance):** CI inside +/-0.10 = "no meaningful excess co-expression"; CI entirely above +0.10 = "consensus pairs are co-expressed more than random pairs"; otherwise inconclusive. Pair-level pooled rho with 95% CI for pairs evaluable in at least 3 datasets. Mouse is analysed separately and never pooled with human. The donor with type 2 diabetes in GSE84133 stays in the primary analysis; the non-diabetic-only result is a sensitivity analysis.
* **4.5 Metacell sensitivity.** Within each donor with at least 40 beta-cells, random partitions into metacells of 20 cells (sensitivity 10 and 50; 20 random partitions), counts summed or RPKM averaged, then 4.2 without depth terms; evaluable = detected in at least 50% of metacells.
* **4.6 Perturbation concordance (route 2).** Fixed GEO query (Notch or gamma-secretase inhibition; DKK1, Wnt inhibitor, beta-catenin or TCF7L2 loss) in islets or beta-cell lines, stem-cell differentiation excluded, at least 3 samples per arm. For each qualifying series: log2 fold changes of the 17 genes against the matching INS-1 arm (Notch series against DAPT, Wnt series against DKK-1): sign agreement with exact binomial test, Spearman r. GSE60803 is a known candidate. Descriptive; different model systems are stated as such.

## 5. MLSS
Independent Python port of `R_17genes/Fig_6c_MLSS_v4.0.r`. **Gate: reproduce all 153 MLSS scores (max absolute difference < 0.005) and the rank order.** Then recompute under: Gapdh variants C0 and C1 (`reanalysis_17genes/gapdh_exact.py`); Synergy Bonus r from each scheme, from the raw treatment-adjusted r, and none; hub rule degree >= 4, 5, 6; potency permuted across drugs and target-mapping permutation (1,000 each, seed 2026). Endpoints: Spearman rho against the reported ranks, top-15 overlap, top pair, share of rank variance explained by potency alone. Direction-aware table: for each hub drug the action type, the target's mRNA change under DAPT and DKK-1, and whether the drug action opposes or adds to that change. Assay types behind the pIC50 values of the top-ranked drugs are listed.

## 6. Reporting assets
Effect sizes (log2 fold change with 95% CI, labelled within-experiment) and across-gene BH for the RT-qPCR panel. Completed MIQE checklist from the Methods, unknown items flagged for the authors. Reusable checker `coexp_checks.py` with command-line interface and tests.

## 7. Interpretation rules fixed now
* A significant T_r2 on real data means within-group coupling exists; it does not identify biology. In INS-1, coupling confined to same-run pairs is read as compatible with shared reference, cDNA or plate effects and not as co-regulation.
* If the calibrated tests contradict a sentence of the manuscript, the sentence changes, including those that favour the paper's conclusions.
* Results on the 17 INS-1 genes never become confirmatory: one preparation, post hoc.
