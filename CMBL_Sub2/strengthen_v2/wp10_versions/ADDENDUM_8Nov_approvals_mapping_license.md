# WP10 addendum (8 Nov 2026, after the user's questions about the Database folder; not part of the fingerprinted pre-specification)

* **Approval lists.** The three small lists of the DrugCentral download page (`FDA_Approved.csv`, `EMA_Approved.csv`, `PMDA_Approved.csv`, 42482, 8099 and 7716 bytes) were downloaded into `Database/` on 8 Nov 06:33 from `https://drugcentral.org/static/`. They are byte-identical to the lists of the reported run (`R_17genes/`), and so is the triple list that the user had downloaded. The approval tiers of all 19 MLSS drugs are therefore unchanged (`results/approval_tiers_old_vs_new.csv`): liraglutide, semaglutide, lixisenatide and glucagon Tier 1; albiglutide, isradipine, nifedipine, felodipine, amlodipine, clevidipine, nimodipine, nisoldipine, bepridil, exenatide and tirzepatide Tier 3 (FDA only); dulaglutide FDA and EMA (neither tier); nitrendipine, (S)-nitrendipine and nilvadipine not approved. Caveat for the text: the tiers are list memberships of DrugCentral, not a regulatory audit (for example tirzepatide is listed FDA-only and dulaglutide is missing from the PMDA list).
* **STRING gene names.** STRING's own identifier mapping (API `get_string_ids`, v12.5, rat, the 17 analyzed names; `results/string_id_mapping_rat_v12_5.tsv`) returns the same name for 16 of the 17 genes; the only name that differs is **Glut2 -> Slc2a2**. The alias of the Fig. 5 correction is therefore complete.
* **Citation.** `10.1093/nar/gkw993` is "DrugCentral: online drug compendium" (Nucleic Acids Research 45, D932-D939; the first DrugCentral paper). The manuscript cites "DrugCentral 2023" for the release it used; for the current release cite the website with the dump date (25 Sep 2026). The website states the license (Creative Commons BY-SA): attribution is required, and the DrugCentral-derived files that are redistributed (for example `drug.target.interaction.csv` in the repository and the potency tables of Additional file 6) should carry that license; the authors should check this before the Zenodo release.
* **Not needed.** The 1.4 GB `Drugcentral_2026-09-25.pgdump` (a PostgreSQL 16 custom-format archive that needs the RDKit extension to restore) was not used: every field of the MLSS is in `drug.target.interaction.tsv.gz`. The DrugCentral DRS API at an AWS App Runner address (version 0.1.0, not an official drugcentral.org or unmtid-dbs.net domain, no release stamp) was not used and is not a reproducible source. The bulk STRING species files (rat, human, mouse; hundreds of MB, all protein pairs) were not downloaded: the 59 edges among the 21 genes come from one API call at the stable v12.5 address.
